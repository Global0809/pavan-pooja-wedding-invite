# Pavan & Pooja Wedding Invitation

A mobile-first wedding invitation for Pavan and Pooja, followed by an interactive 3D baraat experience.

The invitation uses a midnight-teal evening design with blush accents, Bodoni Moda headings, Manrope text, a responsive two-day programme, a dedicated countdown and an animated doorway into the existing 3D world. Films load near the viewport, expose native playback controls and do not autoplay when reduced motion is enabled.

Live invitation: https://global0809.github.io/pavan-pooja-wedding-invite/

Local preview: run `npx http-server . -p 4188 -c-1`, then open http://127.0.0.1:4188/.
